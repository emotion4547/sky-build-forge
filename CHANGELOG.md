# Changelog

Все заметные изменения в проекте документируются в этом файле.

---

## 2026-03-02

### Добавлено
- Иконка поиска в хедер сайта
- Полнотекстовый поиск по контенту (продукция, проекты, статьи) с всплывающими подсказками и категориями (⌘K / Ctrl+K)
- Панель управления калькуляторами в админке (конфигурации, доп. опции, регионы)
- Калькуляторы на фронтенде теперь загружают данные динамически из базы
- Редактируемые расширенные секции, метрики и описания для страниц продукции в админ-панели

### Изменено
- Страница калькуляторов переведена с хардкода на данные из БД
- В раздел «Продукция» перенесён и структурирован контент по типам быстровозводимых зданий без чужого брендинга

### Удалено
- Грачиков Юрий Юрьевич убран из списка контактов на странице «Контакты»

## 2026-04-23

### Добавлено
- Двухуровневый каталог продукции: разделы и подкатегории с отдельными маршрутами и хлебными крошками
- Управление разделами, подкатегориями и товарами в админке через вкладки
- Поиск по разделам каталога и подкатегориям

### Изменено
- Главная секция «Типы зданий» переведена на живые данные каталога и теперь показывает только разделы
- Страница «Продукция» стала верхним уровнем каталога, а подкатегории открываются по гибридной логике
- Карточки товаров получили отдельные витринные поля для каталога
- В админке добавлена автогенерация slug из названия для разделов, подкатегорий и товаров
